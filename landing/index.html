Swingshift

A second shift for unfinished work.

It lets agents take turns on a task and keeps a record of what happened. We made it because a single chat often stops before the work is finished.

Why we made it

There are a lot of tools like this.

This one is small and we think it is useful.

There are plenty of polished AI productivity products. Some are good. We are not trying to explain the whole category.

Swingshift is a tool for a particular problem: you give an agent a task, it gets part of the way, and you keep having to bring it back. We wanted to see if a loop of agents could help.

one taska few agentsa saved record
How it works

Three simple steps.

write → run → check
01 / WRITE

Describe the task.

Write down what you want done. You can start with a rough description.

02 / RUN

Let agents take turns.

One agent works, another checks, and the next one sees the result.

03 / CHECK

Come back to the record.

See what changed, what failed, and whether the task is finished.
